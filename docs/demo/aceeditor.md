# AceEditor编辑器

*ACE Editor 是一个开源的、独立的、基于浏览器的代码编辑器，可以嵌入到任何 web 页面或 JavaScript 应用程序中。ACE 支持超过 110 种语言语法高亮，并能够处理代码多达 400 万行的大型文档。ACE 开发团队称，ACE 在性能和功能上可以媲美本地代码编辑器*

## 使用方式


```
npm install ace-builds --save-dev
npm install vue-loader-v16 -D
```
